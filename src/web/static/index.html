🔑 翻译设置

需要先安装 llama.cpp：winget install -e --id ggml.llamacpp（Vulkan 构建， 装完自动在 PATH 上，上方路径可留空），N 卡想要更快可到 GitHub Releases 下载 llama-*-bin-win-cuda-*.zip 解压后填写上方路径。 本地翻译固定使用 Hy-MT2-7B Q4_K_M GGUF；首次使用自动下载约 4.6GB，建议配合代理。 翻译开始时会临时释放 ASR 显存，任务切回 ASR 时自动重载。 本地模型逐句翻译，不使用术语表、角色参考和全片上下文——这些只在 OpenAI 兼容 API 后端生效。
