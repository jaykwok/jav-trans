jav-sub 安装与使用
====================

双击 jav-sub.exe。第一次运行会先装好运行环境，之后每次双击同一个
jav-sub.exe 就是直接启动程序。

第一次运行会做两件事：

1. 测速并询问代理。
   程序会读取 PyTorch 官方源上的 torch 安装包，报出实测速度和「按这个速度
   要下多久」。速度可以接受就直接回车跳过；太慢或显示「连接失败」，就按
   y 填写本地代理（Clash / v2ray 等）的地址和端口。
   填写的代理会保存到 config\config.json，之后下载 ASR 模型时也会自动使用。
   HTTP、HTTPS 和 SOCKS5 均可用于安装、测速和模型下载。

2. 安装运行环境。
   控制台会实时显示 PyTorch 等依赖的下载进度，安装后约占 3.3GB 磁盘。
   中途断网或关掉窗口都不要紧，重新双击 jav-sub.exe 会接着装，
   已经下好的部分不会重下。

装完会自动打开程序窗口，控制台窗口（黑框）随即自动隐藏；关掉程序窗口就整个
退出。以后启动时控制台显示「jav-sub 启动」并跳过安装。

识别模型（约 3.9GB）在第一次转录时才下载；默认启用本地翻译（Hy-MT3-7B Q4），
本地 CUDA 引擎（约 226MB）会在启动后后台下载到 models\runtime\llama-cpp\，
翻译模型（约 4.8GB）在第一次本地翻译时下载。以上下载均会使用已设置的代理，
模型存放在本目录的 models\ 下。

升级到新版本
------------

推荐方式（在线一键升级）：

程序启动时默认会自动检测 GitHub 最新稳定版（忽略预发布版；可在界面右上角版本号弹窗中
取消勾选「启动时自动检测新版本」关闭）。检测到新版本时，点右上角高亮版本号即可查看更新
说明并点「立即升级」，程序会自动下载、校验、覆盖安装并重启，同时清理升级缓存。也可在
命令行运行：

  jav-sub.exe --update

手动覆盖方式（离线备用）：

1. 关掉程序窗口。
2. 打开新版压缩包，进入里面的 jav-sub 文件夹，全选其中的文件和文件夹，
   复制到旧版的程序文件夹里；提示有同名文件时选「替换」。
   （等价做法：把压缩包解压到旧版 jav-sub 文件夹的上一级目录。）
3. 双击 jav-sub.exe。

运行环境（.venv、.python\）、模型（models\）、设置（config\）、产物（outputs\）与缓存（cache\）
都会保留，不用重新下载。
新版改了依赖时，启动会显示「jav-sub 更新运行环境」，
同样先测速并询问代理（直接回车跳过即可），然后只下载有变化的依赖；依赖没变
的升级直接启动。

旧版本留下、新版本不再使用的程序文件会在启动时移到 tmp\upgrade-leftovers\，
确认新版本正常后可以整个删掉。

不要把压缩包里的 jav-sub 文件夹整个放进旧版文件夹：那样会变成两层
jav-sub，里面那份会重新安装运行环境、重新下载模型。启动时发现这种情况会
先询问。

打不开时怎么办
--------------

每次启动都会先快速检查一遍运行环境。如果 .venv 里的依赖被删掉了（例如为了
腾磁盘），启动时会显示「jav-sub 修复运行环境」并自动补回缺的那几个包，
不会整个重装。

如果程序窗口始终打不开，运行一次自检：

  jav-sub.exe --doctor

它会逐项检查程序文件、FFmpeg 和依赖（会实际导入一遍 torch 等库）并报出缺什么；
缺依赖就当场补装（需要代理时仍读取 config\config.json 里的设置，也可以加 --proxy 指定），
补好后继续启动。

自检提示「程序文件不完整」时，说明缺的是压缩包里的文件，无法自动补回：按上面
「升级到新版本」的做法，把同一版本的压缩包再覆盖一次即可，.venv、.python、models、config
都会保留。

需要注意
--------

* 请把整个文件夹解压到有至少 17GB 空闲空间的位置，不要放在 C:\Program Files
  或其他需要管理员权限的目录——程序要在自己的目录里写入 .venv、.python、models、config、logs、outputs、cache、tmp。
* 需要 NVIDIA 显卡和较新的显卡驱动。驱动过旧时程序会在界面上提示更新。
* 默认启用本地翻译（免费离线，无需配 Key）。如需改用 API 翻译，展开界面左侧「翻译设置」，
  将翻译后端切为 API 调用并填好 API Key 与模型后保存。只要日文字幕时，在「自定义 → 参数调优」
  里打开「不翻译（仅日文字幕）」。
* 如果窗口打不开，安装 Microsoft Edge WebView2 运行时：
  https://developer.microsoft.com/en-us/microsoft-edge/webview2/
* 出问题时，可提供 logs\ 下相关 .run.log、app-<PID>.log 或 asr-worker-<PID>.log
  的报错片段（失败任务的提取音频会保留在 tmp\jobs\<job_id>\audio\）；发送前请勿附带 API Key 或 config\config.json。

命令行参数（可选）
------------------

  jav-sub.exe --update                        检查并在线下载覆盖升级到最新稳定版
  jav-sub.exe --doctor                        检查依赖，缺失就补回来，再启动
  jav-sub.exe --keep-console                  窗口打开后保留控制台（排查问题）
  jav-sub.exe --proxy http://127.0.0.1:7890   指定代理，不询问
  jav-sub.exe --proxy socks5://127.0.0.1:1080 使用 SOCKS5 代理
  jav-sub.exe --yes                           不提问（自检、升级和安装都不等确认）
  jav-sub.exe --reinstall                     重装运行环境
  jav-sub.exe --install-only                  只安装/只自检/只应用更新，不启动
